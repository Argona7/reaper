# Contributing

1. Create a focused branch from `main`.
2. Add or update tests for every behavior change.
3. Run `make check`.
4. Keep money calculations deterministic and permissions outside model prompts.
5. Do not add real statements, credentials, account numbers, or private email text.

Commit messages use Conventional Commits. Pull requests must explain the changed behavior,
the evidence path, the approval impact, and the commands used to verify it.
